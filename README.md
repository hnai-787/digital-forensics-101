# Digital Forensics 101

Hands-on beginner workshop materials for learning how to preserve, verify,
compare, and report digital evidence.

## Contents

- [`index.html`](./index.html) - interactive Case UNI-24 investigation lab
- [`Digital-Forensics-101.pptx`](./Digital-Forensics-101.pptx) - presentation slides
- [`roman-urdu-script.md`](./roman-urdu-script.md) - presenter script
- [`evidence/`](./evidence/) - fictional evidence files used by the lab

## GitHub Pages

The interactive lab is designed to be published at:

https://hnai-787.github.io/digital-forensics-101/

The repository includes a GitHub Actions workflow that deploys the site to
GitHub Pages whenever changes are pushed to `main`.

## Learning objectives

By completing the lab, learners practice:

1. Preserving evidence and creating a working copy.
2. Verifying file integrity with SHA-256 hashes.
3. Comparing file contents and identifying changes.
4. Building a timeline from available records.
5. Recording chain-of-custody gaps and reporting limitations.

This is a fictional teaching case. Examine only the supplied files.
